# Extended Contaminated Negative Binomial Regression Repository

Welcome! 🎉 This repository is designed to make my work on the **Extended Contaminated Negative Binomial (cNB) Regression model** accessible and reproducible. Here you’ll find everything needed to **replicate results, explore plots, and interact with my R Shiny application**.

## 🔍 What’s Inside
- **Code to replicate results** – Scripts to reproduce the analyses and outputs.
- **ShinyApp/** – Source code for the interactive R Shiny application.
- **plots/** – Visualizations generated from the model (e.g., `var_mu_different_eta.png`).
- **rdatasets/** – Example datasets used in the analysis (e.g., `RecreationDemand.rds`).
- **.gitignore** – Standard GitHub housekeeping.

You can explore the model interactively through my deployed Shiny app.

## 📖 Purpose
This repository allows users to:
- Replicate the results I’ve generated using the extended contaminated negative binomial regression model.
- View plots and outputs that illustrate the model’s behavior.
- Access and run the R Shiny app locally or online.
